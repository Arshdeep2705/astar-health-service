Add it to your email

  1. Press Copy signature above.
  2. In Gmail on a computer, click the ⚙️ gear, then See all settings.
  3. On the General tab, scroll to Signature and click Create new. Name it “Astar”.
  4. Click in the signature box and paste (Ctrl+V, or ⌘+V on a Mac).
  5. Under Signature defaults, choose “Astar” for both new emails and reply/forward.
  6. Scroll to the bottom and click Save Changes. Gmail on your phone uses this signature automatically.
  1. Press Copy signature above.
  2. Outlook on the web / new Outlook: ⚙️ Settings → Account → Signatures → New signature.
  3. Classic Outlook for Windows: File → Options → Mail → Signatures… → New.
  4. Name it “Astar”, paste into the box, and set it as the default for new messages and replies/forwards.
